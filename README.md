# Heart Disease Prediction Using Machine Learning

## Project Overview
This project predicts the risk of heart disease based on patient medical attributes using machine learning techniques. The workflow includes data preprocessing, exploratory data analysis (EDA), model training, and evaluation using multiple performance metrics.

---

##  Dataset
The dataset used is a Heart Disease dataset from Kaggle containing medical attributes such as age, blood pressure, cholesterol levels, and other health indicators.

---

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

##  Machine Learning Models
- Logistic Regression
- Decision Tree Classifier

---

##  Project Workflow
1. Data loading and inspection  
2. Data cleaning and handling missing values  
3. Exploratory Data Analysis (EDA)  
4. Feature selection and preprocessing  
5. Train-test split  
6. Model training  
7. Model evaluation  

---

## Evaluation Metrics
- Accuracy Score  
- Confusion Matrix  
- Classification Report  
- ROC Curve  
- AUC Score  
- Feature Importance Analysis  

---

##  Results
The models successfully predict heart disease risk based on patient health data. Logistic Regression provides probability-based predictions, while Decision Tree helps in understanding feature importance.
